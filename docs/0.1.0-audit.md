## Notes that are not issues

- **Tilde:** `--local` / profile `rclone` go through `expand_tilde`. CLI `--rclone` / `--config-dir` do not. Unquoted `~/` is expanded by the shell anyway.
- **Dry-run last-run:** README says synctr still records last-run. Status/`last_run.ok` cannot tell dry-run from a real sync. By design unless the JSON contract grows an additive field later.
- **`profile.rclone` on status objects:** extra optional field vs the README example. Additive; not a second format.
- **`which-rclone` / `profile list` / `schedule generate --json`:** other commands, not a second status schema.
- **No LICENSE file** while `package.license = "MIT"`. Not a 0.1.0 feature claim.
- **CI does not pin rustc.** Folded into #11.

## What 0.1.0 actually ships (when built on stable)

Named profiles on disk, gitignore-style ignores as rclone `--filter-from`, copy/sync/bisync via rclone argv, dry-run, discovery that still finds nix/Homebrew when PATH is short, a TUI, opt-in watch, schedule file write, `status --json` + Noctalia consumer, and a passing test suite on current stable. The P0 is that the declared MSRV and the README test command do not match that suite. The P1s are distribution, status robustness, watch startup, and overlap.
